# RAL

Real Attributes League（FIFA Pro Club League）の大会記録サイトです。
試合結果は Google スプレッドシート「RAL」から読み込みます。

## 公開のしかた

### 1. スプレッドシートを読めるようにする

おすすめは「ウェブに公開」です。

1. スプレッドシートを開き、メニューの「ファイル」→「共有」→「ウェブに公開」を選ぶ
2. 「ドキュメント全体」「ウェブページ」のまま「公開」を押す
3. 表示された URL をコピーし、`config.js` の `publishedUrl` に貼る

「ウェブに公開」を使わない場合は、シートの共有を「リンクを知っている全員が閲覧可」にしてください。
ただしこの方法だと、「節・ラウンド」の列に数字（1、2…）と文字（予選1、決勝…）が混ざっているとき、
文字の方が読み込まれないことがあります。カップ戦を入れるなら「ウェブに公開」を使ってください。

### 2. GitHub に置く

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身（`index.html` `config.js` `logo.png` `.nojekyll` `README.md`）をアップロードする
3. リポジトリの「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存する

数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で見られます。

## データの更新

スプレッドシートに結果を入れるだけで、サイトに反映されます。GitHub 側の作業はいりません。
「ウェブに公開」の場合、反映まで最大5分ほどかかります。右上の ↻ で読み込み直せます。

## エンブレム

「クラブ」タブの「エンブレム」列に、次のどれかを書くと表示されます。空欄のクラブは頭文字の丸になります。

- **GitHubに置く（おすすめ）**：このリポジトリの `emblems` フォルダに画像を入れて、ファイル名（例: `mumei.png`）を書く
- **Googleドライブ**：画像を「リンクを知っている全員が閲覧可」にして、共有リンクをそのまま貼る
- **その他の画像URL**：`https://` から始まる画像のURLを貼る

正方形で背景が透明な画像（256×256px 前後）がきれいに出ます。

## スプレッドシートの構成

| タブ | 中身 |
|---|---|
| 試合結果 | 大会ID、節・ラウンド、グループ、日付、ホーム、得点、アウェイ、PK、区分、備考 |
| 大会 | 大会ID、大会名、種別（リーグ／カップ）、シーズン、開始日、状態（開催中／終了） |
| クラブ | クラブ名、略称、別名（表記揺れ）、エンブレム |
| 処分 | 大会ID、クラブ、勝ち点、適用節、日付、内容 |
| 設定 | 勝ち点、ランキングの点数、レートの重み、カップのラウンド順 |
